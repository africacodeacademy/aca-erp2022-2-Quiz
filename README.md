# React TypeScript Quiz App

A comprehensive quiz application built with React and TypeScript featuring 50 questions covering development concepts used in building the app.

## Features

- 50 technical questions covering React, TypeScript, Git, and development concepts
- Timer-based quiz (50 minutes)
- Score persistence using localStorage
- Detailed results with explanations
- Progress tracking
- Responsive design with Tailwind CSS

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Start the development server: `npm start`
4. Build for production: `npm run build`

## Deployment

This app is designed to be deployed on Vercel with automatic CI/CD pipeline.

## Technologies Used

- React 18
- TypeScript
- Tailwind CSS
- Lucide React Icons
- localStorage for data persistence
